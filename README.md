## About This Repository

This repository documents my learning and practical implementation of Linux fundamentals, cybersecurity reconnaissance, network enumeration, and essential security assessment tools.

The objective is to develop practical cybersecurity skills through hands-on exercises, controlled laboratory environments, command-line tools, and technical documentation.

## Learning Objectives

- Understand Linux files, directories, permissions, users, groups, and processes.
- Learn Linux security fundamentals and system administration.
- Understand passive and active reconnaissance.
- Perform DNS and domain information gathering.
- Learn network enumeration and port discovery.
- Explore essential cybersecurity tools.
- Build a controlled reconnaissance laboratory.
- Document practical exercises, observations, and security findings.
